# Security Policy

## Reporting
Please do not publish exploitable vulnerabilities or private user data in public issues. Until a private security contact is configured, open a minimal public issue asking maintainers for a secure reporting channel; do not include exploit details.

## Current security status
This project is under active development. The initial scaffold is not a security-reviewed release. Vault, encryption and recovery features must not be treated as production-ready until their implementation and tests are complete.

## Scope
Relevant reports include plaintext leakage, vault isolation failures, authentication bypass, key handling flaws, nonce reuse, export/import corruption and data loss.
